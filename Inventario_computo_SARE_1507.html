🔄 Sincronizar entre dispositivos

📱💻 Cómo sincronizar PC y celular
Los datos (incidencias, cambios, notas) se guardan localmente en cada dispositivo. Para sincronizar:
1. En el dispositivo origen: Exportar datos → descarga un archivo .json
2. Envíate el archivo (WhatsApp, correo, Drive, etc.)
3. En el dispositivo destino: Importar datos → selecciona el archivo

⚠️ La importación agrega los registros que no existan; no duplica ni borra los que ya tienes.

📤 Exportar datos de este dispositivo

Genera un archivo JSON con todos los cambios, incidencias y notas guardados aquí (no incluye fotografías para evitar archivos muy pesados).

📥 Importar datos desde otro dispositivo

Selecciona el archivo .json exportado desde otro dispositivo. Solo se agregarán registros que no existan aquí.
